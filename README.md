# Game Menyusun Kata (Word Building) Aksara Jawa

Aplikasi permainan edukatif berbasis JavaScript untuk pembelajaran Aksara Jawa dengan mekanika balok jatuh (*falling blocks*) dan penyusunan kata sesuai **Paugéran Konferensi Bahasa Jawa (KBJ)**.

---

## 📁 Struktur Berkas Proyek

1. **`index.html`** - Berkas halaman utama aplikasi game.
2. **`tetris.css`** - Tampilan UI dengan tema Keraton Jawa Modern (Marun & Emas).
3. **`tetris.js`** - Mesin permainan *Word Building Tetris* (sistem penyusunan kata, skor, level, gravitasi, & efek audio).
4. **`kbj.js`** - Mesin transliterasi dan morfologi kata Aksara Jawa berdasar paugéran KBJ.
5. **`tetris.json`** - Basis data kata target, arti, level, dan susunan suku kata Aksara Jawa.
6. **`ngayogyann.ttf`** - Font khusus Aksara Jawa (Silakan unggah berkas font ini ke direktori utama repositori).

---

## 🚀 Cara Mengunggah & Memasang di GitHub Pages

1. Buat repositori baru di GitHub (misal: `aksara-jawa-game`).
2. Unggah seluruh berkas di atas (`index.html`, `tetris.css`, `tetris.js`, `kbj.js`, `tetris.json`, dan `ngayogyann.ttf`) ke direktori utama (*root*) repositori tersebut.
3. Buka menu **Settings** > **Pages** pada repositori GitHub Anda.
4. Pada bagian **Build and deployment** > **Branch**, pilih `main` / `master` branch dan simpan (`Save`).
5. Aplikasi akan langsung dapat diakses secara publik via tautan GitHub Pages Anda!
